# Browser Level Editor

A browser-based 3D level editor inspired by Unity and Unreal Editor. Will allow online creation and editing of levels
and JSON data be exported for easy use by Unity Devs.

## Tech

- React
- TypeScript
- Three.js
- React Three Fiber
- Zustand

## Features (Planned)

- Object placement
- Gizmos
- Undo/Redo
- Scene hierarchy
- Inspector
- Asset browser
- Save/Load
- Grid snapping
